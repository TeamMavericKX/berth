# Research: portless (vercel-labs/portless)

Cloned 2026-08-21 at commit `2e87792`. v0.15.5, Apache-2.0, npm package `portless`, Node >= 24. Zero runtime dependencies; everything is Node built-ins (http, http2, net, crypto, fs). Core is ~25,100 lines of TypeScript across 42 files in `packages/portless/src`, of which 19 files are tests.

## What it is

A reverse proxy that replaces port numbers with stable named URLs. You run `portless myapp next dev` and reach the app at `https://myapp.localhost`. HTTPS with HTTP/2 is the default. First run generates a local CA, trusts it, and binds port 443 with sudo auto-elevation.

## Architecture, from source

One listener demuxes TLS and plain HTTP by peeking one byte off each socket. Byte `0x16` means TLS ClientHello and routes to an HTTP/2 secure server (`allowHTTP1: true`); anything else gets a 302 to HTTPS. See `proxy.ts:690-706`.

Request path:

1. Read host from `Host` header or h2 `:authority` pseudo-header (`proxy.ts:31-37`).
2. Count hops in `x-portless-hops`. At 5, return 508 with the exact Vite `changeOrigin` fix rendered into the error page (`proxy.ts:60-66, 178-200`).
3. Find route by four-tier match: exact hostname, tailscale authority, tailscale hostname ignoring port, wildcard subdomain (`proxy.ts:113-122`).
4. No match: 404 page lists running apps and prints the command that would register yours (`proxy.ts:203-227`).
5. Match: build X-Forwarded headers, strip h2 pseudo-headers, restore Host for vhost-sensitive backends, dial loopback (IPv4 then IPv6) (`proxy.ts:41-56, 264-268`).

## Details worth copying

- **Route store**: JSON at `~/.portless/routes.json`. Locking via atomic `mkdir`, stale-lock threshold 10s, total budget 15s, exponential backoff 10ms to 100ms with jitter, sync sleep via `Atomics.wait` (`routes.ts:7-19, 117-146`). Conflicts throw `RouteConflictError`; `--force` kills the existing PID.
- **Hosts file**: managed block between `# portless-start` / `# portless-end` markers, entries `127.0.0.1 <host>`. Opt-out via `PORTLESS_SYNC_HOSTS=0` (`hosts.ts:11-12, 55-58`).
- **Worktree prefixes**: `git worktree list --porcelain` counts worktrees; only *linked* worktrees on non-default branches get prefixed. Branch `feature/auth` becomes prefix `auth`; main/master never prefixed (`auto.ts:170-232`). Hostname becomes `<prefix>.<name>.localhost`.
- **Framework injection**: apps get a random port 4000-4999 via the `PORT` env var (`cli-utils.ts:67-70`). Frameworks that ignore `PORT` get flags injected: vite, vp, react-router, rsbuild, astro, ng, react-native, expo (`cli-utils.ts:1095-1140`). Injection reaches through npx/bunx/pnpx/yarn/pnpm runner prefixes (`cli-utils.ts:1143-1150`) and refuses compound commands, env prefixes, comments, and script delegation.
- **Cert operations shell out** to the openssl binary (`certs.ts:231 openssl()`). The CA itself is generated by spawning `openssl`, not linked crypto. Trust install covers macOS keychain, Linux distro detection, Windows including WSL dual-store (CHANGELOG #357).
- **HMR survival**: sets `streamResetBurst: 10000, streamResetRate: 100` so browser RST_STREAM storms during hot reload do not trigger Node's GOAWAY kill at ~1000 resets (`proxy.ts:617-621`).
- **WebSocket over h2**: RFC 8441 extended CONNECT bridged to HTTP/1.1 upgrade against backends; synthesizes Sec-WebSocket-Key since h2 clients never send one (`proxy.ts:471-476`).
- **Service mode**: macOS `/Library/LaunchDaemons/` plist, Linux `/etc/systemd/system/` unit with `Restart=on-failure` `RestartSec=2`, Windows scheduled task XML (`service.ts:620-645, 503-504`).

## Security posture

Loopback-only binding since 0.15.4 (CHANGELOG #361); LAN mode is explicit. Carries real privilege: sudo for :443, root CA in system trust store, writes to /etc/hosts. Heavy engineering spent fencing this in.

## Weaknesses we inherit solutions for

- Requires Node >= 24 at runtime (`package.json:23`).
- TLS/h2 complexity is the bulk of the codebase; an h1-first core is dramatically smaller.
- Injection grammar silently refuses unclassifiable scripts; users must memorize the refusal list (README).
