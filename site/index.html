berth · one binary · zig

One daemon.
Two superpowers.

portless gave dev servers stable https://name.localhost URLs and demanded your sudo, your Node 24, and a root CA. portmap gave agents an honest dashboard and refused to touch TLS at all. berth is both halves, minus the taxes. 

# every app gets a real URL — parallel worktrees never collide
$ berth run -- npm run dev

# frameworks that ignore PORT get real flags, not vibes
$ berth run -- vite dev
berth: viteapp.localhost -> 127.0.0.1:4377 (pid 48330)

# share it: one flag, your tailnet, still zero sudo
$ berth run --funnel -- python -m http.server
berth: exposed at https://box.tail1234.ts.net

The whole job, in one listener

berth peeks the first byte of each connection — the same trick portless uses — and routes TLS to the certificate layer while plaintext flows to the HTTP router. Named URLs land on high ports, so there is nothing to elevate, and /etc/hosts gets one managed block that cleans up after itself.

Named HTTPS, honestly

A local CA minted by the openssl binary you already have — never linked crypto for certificates — signs per-host leaves cached in ~/.berth/certs. Unknown hostnames fall back instead of failing.

An agent-first dashboard

portmap's best idea, kept: send Accept: text/markdown and get the full status page plus API reference as markdown. Humans get HTML; LLMs self-discover kill, label, and refresh endpoints.

Kill with a receipt

SIGTERM every listener on a port, poll zombie-aware for 2 seconds, SIGKILL only survivors, then tell you which thing happened. No lsof dependency, no orphaned children.

Containers speak up

Docker and Podman sockets are polled over plain HTTP-on-a-unix-socket; published ports surface as candidates tagged origin=container. Mystery listeners stop being mysteries.

Mutations wear seatbelts

Kill and edit endpoints check Origin against localhost and honor a bearer token. portmap shipped permissive CORS on a kill endpoint; berth closes that door from day one.

Worktrees just work

Linked git worktrees prefix names with the branch tail — feature/auth becomes auth-myapp — while your root checkout stays exactly as named. Parallel sessions never collide.

Against both parents

Every cell traces to our research dossiers, which cite source lines. We ported solutions, not reverence.

Install & first run

Five-minute human guide lives in docs/guide.md; the agent contract is docs/agents.md.

# build once — no runtime, no npm install, no node_modules
$ git clone https://github.com/TeamMavericKX/berth && cd berth
$ zig build -Doptimize=ReleaseSafe

$ berth run -- npm run dev        # URL printed; ctrl-c cleans up
$ berth trust                     # https URLs browsers believe
$ berth service install           # survives reboots, still no sudo
$ berth clean --yes               # leave with zero residue

Receipts or it didn't happen

The claims above are audited, not asserted. Source-of-truth documents, each with file:line citations:
